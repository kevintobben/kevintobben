# Over de website

## Structuur

```
src/
├── styles/
│   └── global.css          ← Design tokens, buttons, utilities
├── layouts/
│   └── Layout.astro        ← HTML shell + Nav + Footer
├── components/
│   ├── Nav.astro
│   ├── Footer.astro
│   ├── ProjectCard.astro
│   └── sections/
│       ├── Hero.astro
│       ├── About.astro
│       ├── Skills.astro
│       ├── RecentProjects.astro
│       └── Contact.astro
├── data/
│   └── projects.ts         ← Alle projectdata hier aanpassen
└── pages/
    ├── index.astro          ← Homepage (one-pager)
    └── projecten.astro      ← Alle projecten pagina
```
